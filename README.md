A tiny Node 22 program for the make.fun bounty
[Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).

`main.ts` writes one funny single-line one-star review from a house cat
about its human to `/output/entry.txt`: the human stares at his laptop all
day, then calls the cat needy — so the cat sits on the keyboard and fixes
his email. No network, no randomness, no input — the same line on every run.

## Run it

```sh
node main.ts
```
